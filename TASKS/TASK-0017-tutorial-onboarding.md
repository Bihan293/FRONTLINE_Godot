# TASK-0017 — Tutorial and first-launch onboarding

- **Priority:** P1
- **Status:** planned
- **Owner:** OpenCode
- **Dependencies:** Current menu flow
- **Related:** `ROADMAP.md` → P0 первый запуск

## Scope

- First-launch tutorial: movement, aim, fire, reload, stance, grenade, bandage, capture.
- Separate desktop and Android control cards.
- In-match contextual hints: capture sectors, low tickets, no ammo, low HP.
- "Skip tutorial" and replay from main menu.

## Acceptance criteria

- A new player can finish the tutorial without external help.
- Tutorial does not replay on every launch after completion.
- Hints never cover the crosshair or the mobile fire button.
- Tutorial can be replayed from settings/menu.
