# TASK-0024 — Gamepad support and input remapping

- **Priority:** P2
- **Status:** planned
- **Owner:** OpenCode
- **Dependencies:** Stable desktop controls
- **Related:** `ROADMAP.md` → UI/UX

## Scope

- Gamepad: move, look, fire, aim, reload, stance, grenade, pause.
- Remapping screen for keyboard/mouse and gamepad.
- Dead zones, sensitivity per device, prompt glyphs.
- Persist bindings in settings.

## Acceptance criteria

- A full match is playable on a standard XInput gamepad.
- Remaps persist and do not conflict with menu navigation.
- Prompts switch between keyboard/gamepad/touch automatically.
