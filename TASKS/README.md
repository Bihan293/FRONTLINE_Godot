# FRONTLINE task cards

Use this folder for work that still needs to be done. `ROADMAP.md` is the full product plan; `OPEN.md` is the short active queue. Each `TASK-####-name.md` card should have one owner, priority, dependencies, acceptance criteria, and a status.

Statuses: `open`, `in progress`, `ready for review`, `ready for device test`, `done`, `blocked`.

Before starting, check `OPEN.md`, `ROADMAP.md`, and `BUGS/OPEN.md`. Do not mark a task done until its acceptance criteria have been checked. When a card is done, record its PR/commit and move it from `OPEN.md` to `DONE.md`.

OpenCode owns maintaining this task queue and should add newly agreed tasks here rather than duplicating the full checklist in another file.
