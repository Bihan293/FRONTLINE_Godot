# BUG-0007 — Удержание пробела вызывает повторные прыжки

- **Status:** ready for retest
- **Severity:** minor
- **Build / commit:** базовая версия `cbc1b42`
- **Platform / device:** desktop
- **Found by:** Codex QA
- **Frequency:** каждый раз при удержании пробела до приземления
- **Owner:** Codex
- **Fix commit:** pending

## Reproduction

1. Начать матч на ПК.
2. Удерживать Space во время движения.
3. Посмотреть, что происходит при каждом приземлении.

## Expected

Один прыжок на одно нажатие клавиши.

## Actual

Физический цикл проверяет удержание Space и автоматически начинает новый прыжок сразу после приземления.

## Evidence

Статический аудит `scripts/player.gd`: условие прыжка проверялось в `_physics_process` каждый кадр.

## Retest

Проверить после сборки с фиксом, что удержание клавиши даёт только один прыжок.
